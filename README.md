# 智辅化学 ChemAI

面向高中化学教学场景的 AI Agent 教学平台，围绕教师、学生、家长和学校管理员，构建从**答题卡批改、错题诊断、智能出题，到个性化练习、间隔复习和学情反馈**的教学闭环。

> **批改 → 诊断 → 出题 → 练习 → 复习 → 报告 → 干预**

## 产品定位

ChemAI 是面向高中化学的垂直 AI 教学平台，聚焦以下教学场景：

- 纸质答题卡与试卷的数字化识别和批改；
- 结合化学学科规则的 AI 出题与内容审核；
- 从“答错”进一步分析学生的概念、审题和表述问题；
- 根据学生的薄弱知识点匹配个性化练习与复习任务；
- 将教师、学生和家长看到的学习数据连接起来；
- 通过 Agent 对话降低教师使用教学工具的操作成本。

## 四类角色端

### 教师端

- 学校、年级、班级和学生管理；
- 答题卡批量上传与批改任务管理；
- AI 出题、考试配置与考试工作台；
- 历年真题搜索、筛选和相似题关联；
- 化学方程式安全审核；
- 班级错题统计、知识点分析和学情趋势；
- 学生障碍类型诊断和干预建议；
- 个性化学习计划生成与练习布置；
- 题库导入、保存和管理；
- 教师详情报告查看、导出和发送；
- 通过自然语言调用化学教学 Agent。

典型场景：

> “分析这次考试的主要错误。”
>
> “给概念理解薄弱的学生布置一组练习。”
>
> “生成一套化学平衡练习题，并关联历年真题。”

### 学生端

- 查看考试、作业和练习任务；
- 在线答题和提交练习；
- 查看得分、解析和错题记录；
- 查看每道错题对应的错误原因；
- 获取个性化学习计划；
- 完成自适应练习和错题变式训练；
- 按遗忘规律进行间隔复习；
- 查看知识点掌握度和学习趋势；
- 使用 AI 化学助教进行引导式学习；
- 获得离子方程式、物质的量、氧化还原、化学平衡等专题辅导；
- 进行化学实验模拟，理解实验现象、原理和考点。

### 家长端

- 查看孩子的化学学习周报；
- 查看成绩变化和练习完成情况；
- 了解主要学习障碍和薄弱知识点；
- 查看学习计划和阶段性建议；
- 接收成绩变化、学习提醒和报告通知；
- 通过绑定关系查看孩子的学习信息。

家长端采用更易理解的方式说明：

- 本阶段学习了什么；
- 哪些知识点有所进步；
- 哪些问题需要加强；
- 下一阶段可以采取什么行动。

- 学校、年级和班级管理；
- 教师入驻申请和审核；
- 教师、学生和家长账户管理；
- 角色权限和数据隔离；
- 教师与班级、学科关系管理；
- 系统操作日志和审计记录；
- 平台使用情况查看；
- LMS、通知渠道和外部系统配置。

## 核心功能

### 1. OCR 答题卡与试卷批改

支持面向答题卡和试卷的批改流程：

1. 批量上传答题卡或试卷；
2. 识别学号、姓名和作答内容；
3. 提取客观题、主观题及化学表达；
4. 结合题库答案、教师答案和分析结果进行批改；
5. 生成逐题、逐学生批改结果；
6. 支持教师确认和修正；
7. 保存结果并触发错题诊断；
8. 汇总班级错误率和知识点统计。

批改结果可继续用于错题报告、学生诊断、个性化练习和学情面板。

### 2. AI 题库与智能出题

教师可以设置：

- 知识点；
- 题型；
- 难度；
- 题量；
- 适用年级；
- 练习或考试场景。

平台支持：

- AI 生成题目、选项、答案和解析；
- 历年真题按知识点、年份和地区检索；
- 新题与相似真题关联；
- 手动录入和批量导入题目；
- OCR 扫描导入试卷题目；
- 题目按知识点、年份、地区和难度管理；
- 将题目发布到班级或指定学生。

### 3. 化学方程式四维审核

题目生成和导入过程中，围绕以下维度进行化学内容审核：

1. **系数配平**：检查元素原子数量守恒；
2. **反应条件**：检查加热、点燃、催化剂、通电、光照等条件；
3. **产物稳定性**：检查产物在对应反应条件下的合理性；
4. **分子结构**：检查化学式、结构式及分子结构表达。

审核结果支持通过、提示、拦截和人工复核等处理路径。

### 4. 错题诊断与障碍分析

系统围绕三类学习障碍建立诊断体系：

- **概念理解型**：化学概念、规律或知识关系理解不准确；
- **审题障碍型**：没有准确识别题目条件或任务要求；
- **表述障碍型**：思路基本正确，但化学表达不规范。

诊断结果包括：

- 主要障碍类型；
- 对应薄弱知识点；
- 典型错误表现；
- 诊断依据；
- 教学干预建议；
- 推荐练习方向。

教师可以查看班级整体障碍分布和单个学生的长期变化。

### 5. 自适应练习

根据学生的学习状态匹配练习内容，综合考虑：

- 知识点掌握度；
- 错题和连续错误记录；
- 学习障碍类型；
- 当前答题表现；
- 题目难度；
- 历史练习完成情况。

支持班级、学生和知识点维度的练习布置，以及错题变式训练和效果跟踪。

### 6. 间隔复习

将错题和薄弱知识点纳入个人复习计划：

- 根据错题和知识点生成复习任务；
- 按掌握程度划分复习层级；
- 根据答题结果更新掌握度；
- 为不同知识点安排不同复习间隔；
- 优先复习错误率高或遗忘风险高的内容；
- 将复习结果同步到学习计划和学情面板。

### 7. 多层级学情报告与预警

#### 教师详情报告

- 班级成绩和正确率；
- 各题错误率；
- 知识点错误分布；
- 典型错误样本；
- 学生障碍类型分布；
- 需要优先讲评的题目；
- 个体学习情况；
- 后续干预和练习建议。

#### 学生个人报告

- 个人得分和答题情况；
- 错题清单；
- 错误原因；
- 薄弱知识点；
- 推荐练习和复习任务；
- 阶段性学习变化。

#### 家长学习周报

- 本周学习内容；
- 练习完成情况；
- 重点知识点表现；
- 学习进步与待加强方向；
- 下一阶段学习建议。

#### 学情预警

围绕学习数据变化设计预警机制：

- 学习任务完成度变化；
- 连续练习成绩变化；
- 知识点错误率持续偏高；
- 某类学习障碍连续出现；
- 学习计划和复习任务执行情况。

### 8. LangGraph v2 单 Agent

ChemAI Agent v2 采用 LangGraph 单 Agent ReAct 架构，通过自然语言调用化学教学能力。

Agent 设计能力包括：

- 理解教师、学生和家长的自然语言请求；
- 判断任务执行、信息查询和页面导航意图；
- 根据角色匹配工具和数据范围；
- 调度 OCR、出题、诊断、报告、练习和通知能力；
- 通过多轮对话保留上下文；
- 支持流式输出、状态反馈和会话恢复；
- 对关键操作增加前置条件和确认机制；
- 通过角色配置控制工具和数据访问边界。

正式 Agent API：

```text
POST /api/agent/chat/langgraph
POST /api/agent/chat/langgraph/stream
POST /api/agent/chat/langgraph/resume
POST /api/agent/chat/langgraph/reset
```

### 9. Chem Skills 技能体系

Chem Skills 将化学教学能力拆分为可组合技能：

- 历年真题搜索与题库管理；
- 通用化学知识辅导；
- 离子方程式、物质的量、氧化还原、化学平衡、元素周期律和有机化学辅导；
- 化学方程式配平和内容审核；
- 化学实验模拟；
- 学生障碍诊断；
- 学习计划生成；
- 自适应练习布置；
- OCR 进度查询和答题卡批改；
- 批改结果保存；
- 学习周报、家长报告和学习计划发送；
- 学情通知与预警。

### 10. 知识图谱与向量检索

知识图谱描述：

- 化学知识点关系；
- 前置知识与后续知识；
- 知识点与题目关联；
- 知识点与典型错误关联；
- 知识点与练习、复习任务关联。

向量检索用于：

- 相似历年真题搜索；
- 相近知识点和题型匹配；
- 为 AI 出题提供题目参考；
- 为诊断和学生辅导提供上下文；
- 增强题目解析与学习建议的针对性。

### 11. 通知、LMS 与 MCP 集成

通知能力覆盖：

- 新练习发布提醒；
- 学习计划提醒；
- 间隔复习提醒；
- 报告生成通知；
- 成绩变化提醒；
- 学情预警通知；
- 家长周报推送。

平台预留与学校系统的集成能力：

- LMS、LTI 和学校教学平台；
- 钉钉、企业微信等通知渠道；
- 统一身份认证和单点登录；
- 班级、教师和学生信息同步；
- 练习、成绩与报告同步。

MCP 工具可扩展连接：题库、知识库、文档解析、OCR、学情数据、报告、通知和外部教学系统。

## 系统架构

```text
教师端 / 学生端 / 家长端 / 管理员端
                    │
                    ▼
              FastAPI API 层
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
   LangGraph v2   Chem Skills   业务服务层
   单 Agent       化学技能      OCR/题库/诊断/报告/练习
        │           │           │
        └───────────┼───────────┘
                    ▼
        SQLite/MySQL + Chroma + 知识图谱
```

技术组成：

- Python 3.11；
- FastAPI + Uvicorn；
- SQLAlchemy + Alembic；
- LangGraph v2 + LangChain 兼容模型；
- SQLite（开发）/ MySQL（生产）；
- Chroma 向量检索；
- RDKit 化学结构处理；
- Playwright 浏览器自动化；
- Vite 多页面前端；
- KaTeX/mhchem 化学公式渲染；
- ECharts 学情数据可视化。

## 本地启动

### 后端直接托管前端

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
python -m pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

访问：

```text
http://127.0.0.1:8000/
http://127.0.0.1:8000/docs
```

### Vite 前端开发模式

终端一启动后端：

```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8001
```

终端二启动前端：

```bash
cd frontend
npm ci
npm run dev -- --host 0.0.0.0 --port 3000
```

访问：

```text
http://127.0.0.1:3000/
```

## 数据与安全

请勿提交：

- `.env` 和真实 API 密钥；
- SQLite 数据库、WAL/SHM 文件；
- Chroma 运行时索引；
- 学生、教师、家长真实信息；
- 上传答题卡、日志和本地缓存。

请使用 `.env.example` 创建本地配置，并为生产环境设置独立的 JWT 密钥、数据库、CORS 和外部服务凭据。
